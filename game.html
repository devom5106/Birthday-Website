Simon Says Memory Challenge

Repeat the sequence of colors and sounds correctly to score points.

🎮 Level: 1
⭐ Score: 0

Mom, In this game, you will be shown some colored boxes in a grid. When you will start the game, one box will flash and you will have to select that box in the first move. Now, the next box will flash, then you have to select the previous flashed box and the new box in the correct order. Next, one more box will flash, then you will have to select all the three boxes which have been flashed till now, in the correct order. This is the game idea.
